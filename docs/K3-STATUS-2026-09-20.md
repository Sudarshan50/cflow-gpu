
**MEASURED — recorded defect:** Earlier deterministic bodies let a second run inherit the first run's cache. Current source salts bodies per run; older saved artifacts have no salt field.

**INFERRED:** Current harness source is not an exact description of every prior request body.

**MEASURED — source defect:** Gap collection omits the first-to-second nonempty output gap because the first output timestamp is not appended to the gap timestamp list.

**INFERRED:** Saved chunk-gap distributions are incomplete and, with interval `4`, are not token-level ITL.
